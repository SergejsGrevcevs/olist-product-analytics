# Olist Product Analytics

Когортный анализ, оценка retention и PMF, продуктовые метрики
и приоритизация гипотез для маркетплейса Olist.

## Данные

В проекте используются:

- `olist_customers_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_orders_dataset.csv`

## Запуск

Откройте ноутбук `.ipynb` в Jupyter Notebook, VS Code или Google Colab
и запустите ячейки по порядку.
